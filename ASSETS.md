# A Little Light — art

## Portraits
`dist/assets/neighbors.webp` is a WebP copy of the original atlas `art-source/neighbors-v5.png` (1536×1024, 3 columns × 2 rows: Mrs. Sato, Emi, Haru / Kenji, Aiko, the player). It was generated with a built-in image-generation tool as original fictional character art; no Tripo credits were used. The game addresses each cell with CSS background positioning.

Original prompt (abridged): a production portrait sprite atlas for a cozy Japanese neighborhood idle life game — an exact 3×2 grid of square, chest-up portraits in gentle 3D clay storybook style with painterly texture, warm cream/sage/terracotta palette, flat pastel backgrounds, no text: Mrs. Sato (older woman, silver bob, glasses, sage cardigan), Emi (about 35, café apron), Haru (about 28, round glasses, blue sweater), Kenji (about 55, gardening jacket), Aiko (about 45, plum cardigan), and an adult male traveler (short brown hair, beard, sage jacket, backpack). Respectful, natural depictions; no logos or watermarks.

## Fallback town
`dist/assets/neighborhood.webp` (1400 px wide) comes from `art-source/neighborhood.png`, an original generated painting of a spring Japanese residential neighborhood with blank signboards. It is shown only on devices without WebGL.

## Everything else
The 3D town, buildings, people, signs and icons are drawn by code (`dist/world/`). `dist/icons/icon.svg` is the source for the PNG app icons. Local leaders' seals are kanji drawn in the page's fonts. Japanese fonts (Zen Maru Gothic, Shippori Mincho) load from Google Fonts.
